# Regulation: atomic fundamentals

Use selectively after the shared bank. Each item tests one issue. These are diagnostic questions, not universal prerequisites. Reuse what is already known; surface only gaps that matter to the current decision. Technical and legal items are checks to investigate, not assertions that a rule applies.

## Activity and jurisdiction

- REG-001: What activity will Convertia actually perform?
- REG-002: What legal classification could apply to that activity?
- REG-003: What evidence supports that classification?
- REG-004: Which jurisdiction governs the activity?
- REG-005: Which local authority can decide the issue?
- REG-006: Which requirement changes with the proposed use?
- REG-007: Which requirement changes with the location?
- REG-008: Does the commercial label obscure the actual activity?
